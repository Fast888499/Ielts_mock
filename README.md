# Ielts_mock
IELTS-style mock tests and personalized English learning tutor for A2-B1 learners.


IELTS Mock & Personal Tutor
A2–B1 darajasidagi ingliz tili o‘rganuvchilar uchun IELTS-uslubidagi mashqlar, diagnostika va shaxsiy fikr-mulohaza berishga mo‘ljallangan skill.
Nimalar qiladi?
Dastlabki diagnostika: Reading, Grammar, mini Writing va Speaking.
Reading: darajaga mos matn va 8 savolli mashq.
Listening: audio mavjud bo‘lmaganda cheklovlari ochiq aytilgan matnli simulyatsiya.
Writing: qisqa o‘quv mashqlari va to‘liq IELTS-uslubidagi topshiriqlarni farqlash.
Speaking: Part 1, Part 2 va Part 3 mashqlari.
Xatolarni tahlil qilish va xato daftari.
Imtihon sanasi va foydalanuvchining bo‘sh vaqtiga mos tayyorgarlik.
O‘rnatish / ishlatish
SKILL.md faylini skill qo‘llab-quvvatlaydigan agent yoki platformaga joylashtiring.
Skill metadata'sidagi name va description maydonlarini saqlang.
Skillni IELTS mashqi, mock, Writing tekshiruvi yoki Speaking mashqi so‘ralganda ishga tushiring.
Platformaga qarab skillni o‘rnatish tartibi farq qilishi mumkin. Ushbu repozitoriy universal GitHub manba paketi sifatida tayyorlangan.
Fayllar
SKILL.md — asosiy skill ko‘rsatmalari.
TESTING.md — test rejasi, assertionlar va test natijalarini halol qayd etish qoidalari.
Muhim cheklovlar
Bu rasmiy IELTS imtihoni yoki rasmiy IELTS baholash vositasi emas.
Qisqa mashqlar o‘quv maqsadida moslashtirilgan; ular rasmiy imtihon topshiriqlarining o‘rnini bosmaydi.
Matn asosidagi Listening haqiqiy audio sinovi emas.
Yozma javobdan talaffuz va og‘zaki fluency baholanmaydi.
IELTS band score, imtihondan o‘tish yoki natija kafolatlanmaydi.
Test holati
Ushbu repozitoriy bilan birga keladigan TESTING.md hujjatida test ssenariylari va assertion mezonlari berilgan. Mustaqil, qayta bajariladigan A/B benchmark natijalari mavjud bo‘lmaguncha, testlar modelning umumiy ustunligini yoki token/vaqt tejamkorligini isbotlaydi deb da’vo qilinmaydi.
Litsenziya
Hozircha litsenziya fayli qo‘shilmagan. Repozitoriyni ommaga tarqatishdan oldin kerakli litsenziyani tanlang (masalan, MIT yoki Apache-2.0). Litsenziya tanlanmaguncha boshqalarga foydalanish, o‘zgartirish yoki tarqatish huquqi avtomatik berilgan deb hisoblamang.
